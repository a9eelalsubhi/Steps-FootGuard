# STEPS · خطاك / FootGuard

الموقع الكامل للعرض التفاعلي بالعربية والإنجليزية، مع الصور والخطوط والحركات وجميع ملفات التشغيل المحلية.

## الرفع إلى GitHub

1. فك ضغط ملف ZIP.
2. افتح مجلد `Steps-FootGuard-GitHub` وارفع محتوياته إلى المستودع `Steps-FootGuard`، بحيث يظهر `index.html` مباشرة في جذر المستودع بجانب `README.md` ومجلد `assets`.
3. ارفع الملفات والمجلدات بعد فك الضغط؛ لا ترفع ملف ZIP نفسه بوصفه الموقع.
4. لتشغيله عبر GitHub Pages، اختر النشر من الفرع `main` ومجلد الجذر `/ (root)` من إعدادات Pages للمستودع.

الرابط المتوقع عند تفعيل Pages للمستودع الظاهر في الصورة:
https://a9eelalsubhi.github.io/Steps-FootGuard/

العربية: `?lang=ar#1` — الإنجليزية: `?lang=en#1`.

## التشغيل والتعديل

الموقع ثابت، ولا يحتاج تثبيت حزم أو بناء مشروع أو مفاتيح API. يمكن فتح `index.html` مباشرة أو تقديم المجلد عبر أي خادم ملفات ثابتة.

- `index.html`: صفحة الدخول وعناصر التحكم.
- `app.js`: المشاهد والتنقل وتبديل اللغة.
- `revision.js`: تحسينات المشاهد ومحتواها.
- `motion.js` و`motion.css`: الحركة والمؤثرات.
- `style.css` و`revision.css` و`brand.css`: التنسيق والهوية.
- `source-content.js` و`source-content.json`: المحتوى والمراجع.
- `assets/`: جميع الصور والخطوط والأيقونات والرسوم.

اختصارات العرض: الأسهم للتنقل، Space للتشغيل التلقائي، L للغة، F لملء الشاشة، G للفهرس، N للمصادر، Home وEnd للبداية والنهاية. زر الحركة يقلل المؤثرات، ويُحترم تفضيل تقليل الحركة في النظام.

الخط العربي: ثمانية. يتضمن الموقع 22 مشهدًا باللغتين. ملفات الأصول مضمنة محليًا؛ الروابط الخارجية للمراجع والنموذج الأولي والملفات المهنية تحتاج اتصالًا بالإنترنت.
