# خطاك STEPS · FootGuard — الموقع المحسَّن

نسخة محلية من العرض التفاعلي المنشور، مع التحسينات التالية:

- **وضع الجوال** (`phone.css`): على الشاشات الطولية الضيقة تتحول المشاهد إلى صفحة عمودية مقروءة بدل تصغير إطار 16:9.
- **بطاقة المعاينة** (`assets/og-image.png` + وسوم og/twitter في `index.html`): تظهر عند مشاركة الرابط في واتساب والبريد.
- **الحركة** (`scan.js`, `scan.css`, GSAP في `assets/vendor/`):
  - الغلاف: بطاقة فحص مباشر (بصري ← حراري ← ضغط ← النتيجة).
  - مشهد عوامل الخطورة: مؤشر ΔT يتجاوز 2.2°C ويظهر إنذار مبكر.
  - مشهد الإصابات: مسار المشي منى ← عرفات ← مزدلفة.
  - الحل المقترح: نقاط بيانات تنتقل من المدخلات إلى مركز القرار ثم المخرجات.
  - المقارنة: ظهور الصفوف تدريجيًا وإضاءة صف خطاك.
  - كل الحركة تحترم «تقليل الحركة».
- **صفحة المحكّمين** (`judges.html`): الفيديو، الروابط الثلاثة، المشروع في 30 ثانية، الملخص، الفريق.
- **الملخص التنفيذي** (`assets/STEPS-executive-summary.pdf`) و**فيديو العرض** (`assets/pitch.mp4`، 81 ثانية).
- ملفات التصميم المصدرية في `design/` (بطاقة المعاينة، الملخص، الفيلم).

## التشغيل محليًا
```
python -m http.server 8765
```
ثم افتح http://localhost:8765/?lang=ar#1 و http://localhost:8765/judges.html

## النشر
الموقع ثابت بالكامل. ارفع محتويات المجلد إلى مستودع GitHub وفعّل Pages من الفرع `main` والجذر.
وسوم المعاينة تشير إلى `https://a9eelalsubhi.github.io/Steps-FootGuard/` — غيّرها إن نُشر الموقع على عنوان آخر.

بعد أي تعديل على ملفات css/js شغّل `python bump.py` لتحديث أرقام الإصدار ومنع المتصفح من استخدام نسخة قديمة.
